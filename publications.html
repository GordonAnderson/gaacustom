How to Reference

Citing GAACE Hardware in Your Methods

We don't ask anyone to cite us. But naming the electronics in your instrument description helps other groups reproduce your work — and it's how we find out what our hardware is being used for. If it's useful, here is the wording.

Standard vendor form
GAA Custom Electronics, LLC, Kennewick, WA, USA
A MIPS controller in an instrument description
All DC and RF potentials were supplied by Modular Intelligent Power Sources (MIPS) controllers (GAA Custom Electronics, LLC, Kennewick, WA).
A standalone instrument or module
Ion gating was performed with a FET pulser (GAA Custom Electronics, LLC, Kennewick, WA).
Two things worth getting right. The company name is GAA Custom Electronics — "GAA Custom Engineering" appears in some published papers and refers to the same company under a former name. And MIPS stands for Modular Intelligent Power Sources; spelling it out on first use avoids confusion with the processor architecture of the same name, which also makes your paper findable by other groups searching for the platform.
Design files. Firmware, host application source, and an increasing number of hardware design packages are published on GitHub under open licences. If you need a schematic or board file that isn't posted yet, ask us — we share technical data with researchers using our hardware and we don't require an NDA. See our open source practice for the licence details.
