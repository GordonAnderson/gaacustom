MIT LICENSE HEADER — for in-house GAACE source files
=====================================================

Add this block to the top of each source and header file in the in-house
libraries (DIhandler, SerialBuffer, WireServer), and any other GAACE-authored
files that currently have no license header.

Minimal SPDX-only variant (if you prefer a short header + a LICENSE file)
-------------------------------------------------------------------------

If each library folder has its own MIT LICENSE file, the per-file header can be
just:

/*
 * <FileName> — part of <LibraryName>
 * Copyright (c) 2026 GAA Custom Electronics, LLC
 * SPDX-License-Identifier: MIT
 */

This is the cleaner approach for many files — put the full MIT text once in a
LICENSE file in the library folder, and use the short SPDX header everywhere.


Per-library LICENSE file
------------------------

Drop a file named `LICENSE` in each in-house library folder containing the full
MIT text with this copyright line:

    Copyright (c) 2026 GAA Custom Electronics, LLC

(The MIT text is in the licensing kit at firmware-repo/LICENSE — copy it and
fill the copyright line, or use GitHub's MIT template.)
